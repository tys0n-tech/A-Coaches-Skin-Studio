# โมเดลพรีวิวในโปรแกรม

v0.3.0 รวมโมเดล 5 รุ่นใน `resources/models/` และผังลายใน `resources/templates/` โปรแกรมอ่านทั้งสองชุดอัตโนมัติตามรุ่นที่เลือก

โมเดล Volvo 9700 DD ปรับปรุงประกอบด้วยเบาะ ผ้าม่าน รายละเอียดภายใน และวัสดุกระจก โดยคง UV สำหรับลายตัวถังไว้

## นำเข้าโมเดลเพิ่มเติม

ใช้ปุ่มนำเข้าโมเดล 3D เพื่อเปิด GLB จากเครื่อง ไฟล์ควรมี UV ตัวถังและวัสดุแยกสำหรับกระจก ล้อ และไฟ เลือกวัสดุหลายรายการและ UV แต่ละรายการได้ในโหมดกำหนดเอง

การสร้างมอดอัตโนมัติใช้รุ่นรถในรายการหลัก หากนำเข้าโมเดลอื่น สามารถใช้การแก้แพ็ก .scs เดิมในเมนูเพิ่มเติม

ไฟล์ต้นฉบับของโมเดลและพื้นผิวรถมาจาก SCS Software รายละเอียดทรัพยากรอยู่ใน resources/ASSET-NOTES.txt
