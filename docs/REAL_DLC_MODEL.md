# ใช้โมเดล Coaches DLC ของผู้ใช้กับ 3D Preview (แนวทาง)

เพื่อพรีวิวให้ตรงเกม จำเป็นต้องใช้ 3D geometry และ UV จากรถ DLC ไม่ใช่ reference geometry ภายในแอป

## ขั้นตอนสำหรับไฟล์ที่คุณมีสิทธิใช้งาน

1. ติดตั้ง Blender และเครื่องมือ import model ของ SCS ที่รองรับเวอร์ชันที่คุณใช้ เช่น SCS Blender Tools/ConverterPIX (ตรวจเวอร์ชันที่ผู้พัฒนาระบุ)
2. ตรวจว่า DLC Coaches ติดตั้งจาก Steam; เลือกโฟลเดอร์เกมจากแอปเพื่อดูรายการ archive ที่ระดับ root (แอปยังไม่แตก archive ให้อัตโนมัติ)
3. ใน Blender ใช้ importer ที่รองรับ SCS archives นำเข้าโมเดลจากไฟล์เกมที่คุณเป็นเจ้าของ / ได้รับอนุญาต; บาง archive อาจไม่เปิดได้ตาม tool version
4. หา Mesh ของตัวถังที่มี UV และเลเยอร์สี (paintjob) ที่ต้องการ; อย่าเอาทั้งตัวรถไปเป็น material เดียว เพราะกระจก ล้อ และไฟไม่ควรรับภาพเดียวกันทั้งหมด
5. กำหนด UV ให้ตรงกับลายที่ทำใน Figma; ตรวจว่า GLB exporter ไม่ทำให้ UV channel หาย
6. Export **glTF Binary (.glb)** จาก Blender โดยรวม geometry + UV + วัสดุจำเป็น ไม่ต้องฝังไฟล์ลิขสิทธิ์ไว้ในโปรเจ็กต์ซอฟต์แวร์
7. เปิดแอป กด **นำเข้าโมเดล 3D** > เลือก GLB > เลือก Mesh ของตัวถัง > เพิ่ม PNG

เลือกวัสดุได้หลายรายการในโหมดกำหนดวัสดุและ UV เอง ส่วนลายกระจกข้างใช้ช่องนำเข้าภาพแยกและต้องใช้โมเดล Scania 13.7 ม. ที่รองรับ รายละเอียดอยู่ใน [คู่มือการใช้งาน](../README.md)

## ทำไมไม่รวมโมเดล Coaches ใน ZIP?

เพราะเป็นทรัพย์สินจาก DLC ที่มีลิขสิทธิ์ของผู้พัฒนาเกม และเวอร์ชันนี้ไม่ย้ายหรือแจก assets เกม แนะนำให้ import จากสำเนาที่คุณมีสิทธิใช้งานเอง ไม่เผยแพร่ GLB ที่แปลงจาก DLC ต่อเป็นสาธารณะ

## คำเตือนด้านความเข้ากันได้

โครงสร้างการเก็บไฟล์หรือวิธีแปลงอาจเปลี่ยนไปหลังแพตช์เกม; ตรวจ log จาก Blender/converter หาก importer ไม่รู้จัก model version และใช้วิธีแปลงที่ได้รับอนุญาต ไม่รับประกันว่าจะ import ได้ทุกตัวถังใน 1.62
