# Coaches Skin Studio v0.4.1

The supplied A-Coaches Skin Studio logo is now used for the Windows executable, application window, taskbar identity, app header, and favicon.

The Windows icon includes sizes from 16 × 16 to 256 × 256. The original artwork is preserved.

All five coach variants retain body and side-window livery support from v0.4.0.

Download the Windows x64 ZIP, extract the entire folder, and open Coaches Skin Studio.exe.

The Windows application is unsigned. SHA256SUMS.txt is included for download verification.
